# object-oriented-cpp-labs
This repository contains a structured collection of **lab exercises and mini-projects** focused on **Object-Oriented Programming (OOP)** using **C++**. These labs were completed by me during my Object-Oriented Programming course as part of my undergraduate studies in Computer Science. It is designed to cover all major OOP concepts from beginner to advanced level, making it a useful resource for students, self-learners, and developers revising C++ OOP principles.

---

## Overview

These labs are designed to help learners:

- Build a strong understanding of OOP principles.
- Apply theoretical concepts through practical coding tasks.
- Gain hands-on experience in implementing C++ class hierarchies, polymorphism, templates, and more.

## 🧠 Concepts Covered

- Classes and Objects
- Constructors and Destructors
- Inheritance (Single, Multi-level, Hierarchical, Multiple)
- Friend Functions and Classes
- Static Members
- Encapsulation and Data Hiding
- Composition and Aggregation
- Operator Overloading
- Function Overloading and Overriding
- Polymorphism (Compile-time and Run-time)
- Abstract Classes and Interfaces
- File Handling with Classes
- Templates and Generic Programming
- Exception Handling in OOP Context

## 🛠️ Technologies Used

- Language: C++
- IDEs: Code::Blocks / Visual Studio / g++
- OS: Windows / Linux (cross-platform compatible)
